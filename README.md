# Web Chat Application

A real-time web chat application designed with a clean and modern user interface.
The project focuses on smooth communication, responsive layout, and component-based
frontend architecture.

## 🚀 Features
- Real-time chat user interface
- Sidebar for contacts and conversations
- Chat window with message display
- Responsive layout for desktop and mobile
- Clean and reusable React components

## 🛠️ Tech Stack
- React.js
- JavaScript (ES6+)
- HTML5
- CSS3 / Tailwind CSS
- Context API for state management

## 📁 Project Structure
- Sidebar component for chat list
- Chat component for messaging UI
- Reusable UI components
- Centralized state management

## 🎯 Purpose
This project demonstrates frontend skills in building interactive applications,
handling UI state, and designing scalable component structures similar to
real-world chat platforms.
